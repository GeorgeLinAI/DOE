# `st_doe.py` 實驗設計 (DoE) 互動產生器 說明文件

## 1. 專案簡介
`st_doe.py` 是一個基於 [Streamlit](https://streamlit.io/) 開發的網頁互動應用程式。其主要功能是讓使用者透過圖形化介面（GUI）輸入參數，自動產生 **Resolution IV (或以上)** 的二水準正交實驗表（Two-Level Fractional Factorial Design）。

本程式結合了專案內的 `DOE.py` 核心邏輯模組，將複雜的實驗設計流程簡化為直觀的網頁操作，幫助工程師或研究人員快速建立實驗計畫。

## 2. 系統需求與依賴套件
- **Python版本**：建議 3.8 以上
- **依賴套件**：
  - `streamlit` (用於構建網頁介面)
  - `pandas` (用於資料表處理與呈現)
  - `numpy` (數值計算)
  - `DOE` (專案內建的實驗設計核心邏輯模組 `DOE.py`)

*註：若使用 `uv` 進行環境管理，可使用指令 `uv pip install streamlit pandas numpy` 進行安裝。*

## 3. 畫面與佈局架構
網頁採用左右分欄（比例為 1:2）的寬螢幕設計：
- **左側欄 (參數設定區)**：提供使用者輸入實驗所需的變數。
- **右側欄 (結果展示區)**：根據左側設定，即時計算並顯示產出的 DoE 實驗表。

## 4. 核心功能說明

### 4.1 參數設定 (左側欄)
使用者可在此區塊調整實驗的關鍵參數：
1. **目標值數量 (Responses)**：
   - 設定實驗欲觀察的結果指標數量（範圍：1~5，預設為 1）。
2. **因子數量 (Factors)**：
   - 設定參與實驗的變數數量（範圍：2~15，預設為 5）。
3. **定義因子名稱與範圍**：
   - 系統會根據「因子數量」動態產生對應數量的輸入區塊（Expander）。
   - 每個因子皆可自訂：
     - **名稱**：因子的具體名稱（預設為 因子_1、因子_2...）。
     - **小值 (Min)**：該因子的低水準數值（預設為 -1.0）。
     - **大值 (Max)**：該因子的高水準數值（預設為 1.0）。
   - *為保持介面簡潔，預設僅展開前 3 個因子的設定面板。*

### 4.2 資料處理邏輯 (`build_sheet` 函式)
前端收集完參數後，會交由 `build_sheet` 函式處理，該函式串接了 `DOE.py` 的核心 API：
1. `DOE.build_factorial(n_factors)`：建立基礎的因子矩陣。
2. `DOE.check_factor(n_factors, factor_configs)`：檢查前端傳入的因子設定是否有誤，並提取出名稱、最大值與最小值。
3. `DOE.assign_values(...)`：將 -1 與 1 的標準正交表轉換為使用者設定的實際數值範圍。
4. `DOE.build_final_sheet(...)`：組合最終的資料表，包含標準順序（`std_order`）、執行順序（`run_order`）以及預留的目標值欄位。

### 4.3 結果展示 (右側欄)
- **錯誤提示**：若因子設定有邏輯錯誤（如小值大於大值），會在上方顯示提示訊息。
- **互動式資料表 (`st.data_editor`)**：
  - 以互動式表格呈現最終的實驗計畫。
  - **鎖定欄位**：`std_order` (標準序) 與 `run_order` (隨機執行序) 會被鎖定，禁止使用者修改，以確保實驗設計的嚴謹性。
  - 使用者可直接在表格上預覽或進一步填寫實驗數據。

## 5. 如何執行與使用
打開終端機（Terminal），切換到專案目錄後，使用 Streamlit 指令啟動應用程式：

```bash
# 如果使用一般 Python 環境
streamlit run st_doe.py

# 如果專案強制使用 uv 管理
uv run streamlit run st_doe.py
```
執行後，瀏覽器將自動開啟 `http://localhost:8501`，即可開始使用互動式 DoE 產生器。

# `st_analysis.py` 實驗數據分析與最佳化模型 說明文件

## 1. 專案簡介
`st_analysis.py` 是一個基於 [Streamlit](https://streamlit.io/) 構建的互動式資料分析與建模網頁應用程式。其主要目標是接收實驗設計 (DoE) 執行後的數據結果，進行顯著性分析、殘差診斷、中心點曲率檢定，並透過演算法幫助使用者尋找能達到最佳化目標的生產或實驗參數。

本程式整合了強大的統計模型（如 `statsmodels`）與數值最佳化演算法（如 `scipy.optimize`），將以往複雜的統計軟體操作簡化為友善直觀的網頁操作流。

## 2. 系統需求與依賴套件
- **Python版本**：建議 3.8 以上
- **依賴套件**：
  - `streamlit` (網頁介面框架)
  - `pandas` (資料處理)
  - `numpy` (數值計算)
  - `statsmodels` (進行 OLS 迴歸與統計檢定)
  - `matplotlib` (繪製殘差分析圖與 Q-Q plot)
  - `scipy` (最佳化求解、分配檢定)

*註：若使用 `uv` 進行環境管理，可使用指令 `uv pip install streamlit pandas numpy statsmodels matplotlib scipy` 安裝相關依賴。*

## 3. 核心分析流程與功能

本系統採用六階段的引導式分析流程，說明如下：

### 步驟 1：檔案上傳與資料清理
- 支援上傳 `.csv` 格式的實驗數據。
- 自動清理欄位名稱（去除特殊字元等），以符合後續建模的語法規範。
- 提供展開式視窗，讓使用者預覽原始資料並查看基礎敘述統計數據。

### 步驟 2：設定模型參數 (反應變數 Y 與因子 X)
- 讓使用者選擇欲分析的 **反應變數 (Y)** 與 **影響因子 (X)**。
- 系統會自動判斷 X 是「連續型數值變數」或「類別型變數」。若為類別型，會自動套用虛擬變數編碼（使用 `C()`）。

### 步驟 3：OLS 模型自動篩選 (向後消去法)
- 系統會自動組合所有主效應 (Main Effects) 與二階交互作用 (2-way Interactions)。
- 採用 **向後消去法 (Backward Elimination)**，逐步剔除 P-value 大於 0.1 的不顯著因子（不受強制階層原則限制）。
- 自動列印每次被剔除的因子與其 P-value，並於最後展示最佳化後的多元迴歸方程式與 OLS 分析總表。

### 步驟 3.5：中心點曲率分析 (選配)
- 透過 F 檢定（F-test）檢查系統中是否存在**曲率 (Curvature)**。
- 使用者可利用「旗標欄位」或「手動勾選列號」標記實驗數據中的中心點。
- 系統根據純誤差（Pure Error）檢定模型線性是否足夠：
  - **顯著 (P < 0.05)**：建議升階為反應曲面法（RSM / CCD / Box-Behnken）。
  - **不顯著**：當前的線性與二階交互作用模型足以解釋數據。

### 步驟 4：殘差分析 (Residual Analysis)
- 系統自動產生並呈現兩張重要的診斷圖：
  1. **Residuals vs. Fitted (殘差圖)**：檢查變異數是否齊一（有無漏斗狀）及模式是否良好。
  2. **Normal Q-Q Plot (常態機率圖)**：驗證殘差是否符合常態分配假設。

### 步驟 5：自動尋找最佳生產參數
- 使用者可設定最佳化目標：**最大化 (Maximize)**、**最小化 (Minimize)** 或 **給定目標值 (Target)**。
- **演算法核心**：
  - **類別因子**：採用枚舉所有可能組合。
  - **數值因子**：採用多起點全域優化演算法 (`scipy.optimize.differential_evolution`)，搜尋範圍會自動往外延伸原資料範圍的 30%。
- 計算完成後會顯示最佳化目標的預測數值與詳細參數配置表，並自動儲存至 Session 供下一步使用。

### 步驟 6：互動式手動預測模擬器
- 讀取最佳化的結果參數，作為控制項的預設值。
- 以 **下拉選單 (類別因子)** 與 **滑動軸 (數值因子)** 的方式呈現所有 X 因子。
- 當使用者手動微調任意參數時，系統會即時重新計算並顯示預測的 Y 值，方便工程師進行 Sensitivity 測試。

## 4. 如何執行與使用
打開終端機（Terminal），切換到專案目錄後，使用 Streamlit 指令啟動應用程式：

```bash
# 如果使用一般 Python 環境
streamlit run st_analysis.py

# 如果專案強制使用 uv 管理
uv run streamlit run st_analysis.py
```
執行後，瀏覽器將自動開啟 `http://localhost:8501`，即可開始匯入您的 CSV 數據並進行分析。
